The event runs 16–30 October. Submission closes on 30 October at 11:59 pm IST. Choose one track and submit one project. The current event page describes solo participation. It permits assistants/builders and keyboard shortcuts while emphasizing dictated prompts, documentation and messages.

Judges need an accessible working project, a video no longer than two minutes, the official Wispr usage screenshot and a concise problem/user/voice-use explanation. The current submission form also asks for product feedback. Keep the guest demo available without account registration.

The announcement assigns 30% to the real problem, 30% to Wispr use, 25% to functionality and 15% to demo clarity. The usage bonus relies on the desktop usage card, which Wispr verifies. Our app's text or artifact counters are not that evidence. Weekly progress posts use #NoHandsChallenge and tag the organizers.

## SpecFlow's focused story

For an engineering lead, translating a project discussion into actionable work takes repeated writing. SpecFlow lets the lead dictate a decision, inspect source-backed requirements, refine scope and confirm issue creation or a team update in connected accounts.

Show a complete workflow rather than unrelated generated panels: guest entry; a real dictated brief; a specific voice correction; source review; explicit delivery preview; one authorized real issue/message; its provider receipt.

Use Flow throughout development and testing: dictate requirements into the coding assistant, narrate corrections, write documentation with Flow, refine selected acceptance criteria with eligible Command Mode, and create relevant personal snippets/dictionary entries in Flow. Record actual usage; do not inflate counts or represent simulated text input as microphone testing.

## Readiness checklist

- Public guest path works without sign-up or payment.
- Firebase sign-in and project isolation are verified on the final domain.
- AI generation succeeds with configured provider access; fallback limitations are visible.
- OAuth app registrations, approved callback URLs and encrypted credential storage are configured.
- One real GitHub issue and one Slack message are confirmed in authorized test destinations.
- Two-minute video, official Wispr usage card, feedback and build-in-public links are ready.

OAuth and provider setup are distinct from implementation. Do not call the submission ready until live account verification is complete.
